## 技術スタック

- **フレームワーク:** Next.js 16, React 19
- **言語:** TypeScript 5  
- **スタイリング:** Tailwind CSS 4
- **多言語対応:** next-intl (EN/RU/JA)
- **デプロイ:** Vercel

## 主な機能

- 3ヶ国語対応（英語/ロシア語/日本語）
- スムーズなアニメーション
- 完全レスポンシブ対応
- インタラクティブな演出（紙吹雪、効果音）
